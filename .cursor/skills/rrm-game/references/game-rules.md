毎ターン **4択から1つ**。

| 行動 | 内容 |
|------|------|
| **仕事** | 約1,300G（キャラ・善行で変動）、善行+10 |

| **デイリースロット** | 500G（250G×2）支払い、技量育成。**1回目・2回目はそれぞれボタンで開始**（自動連続なし） |

**共通（毎行動後）**

- 生活費を引く（マイナス＝借金）
- PON +5（キャラ倍率あり）

## PON（炎上）

- **PON ≥ 30**（`BAL.pon.fireThreshold`）で、対象行動ごとに **PON% の確率**で発火
- **配信** → 大炎上（資金+300〜800G、技量-20）。リリムは配信倍率永続UP
- **仕事** → 弁償（資金-200〜500G）
- **神社・デイリースロット** → **発火判定なし**（ペナなし）
- 炎上後 PON は半減
- **8日目**移動中も転倒などあり

## 8日目：決戦

### ラウンド構造

- **15ラウンド固定**（`remainingTurns` 15→0）
- 全員が1ラウンド分終えると1減る
- **移動もスロットも「手番ごと都度付与」**（事前 bank なし）

### すごろく（盤上）

- **50マス**（`BOARD_GOAL`）をゴール目指す
- 手番が来て `moving` の間、**1回移動**（ダイス／タクシー等）
- マス効果：前進・後退・お金・PON上昇・**借金トラップ** 等
- **借金トラップ**（借金中に踏む）→ ソロ：ゲームオーバー / マルチ：脱落

| 追加行動 | 内容 |
|----------|------|
| **タクシー** | **600G**（`BAL.dice.taxiCost`）で12〜18マス（渋滞リスク） |
| **コンビニ** | 150G でダイス+1 |
| **人助け** | 30%発生、善行UP。PON≥80で50%即死 |

### ゴールとスロット

```
【ゴール】
  盤上を離れるだけ（スピン bank なし）

【自分の手番（ゴール済み・waitingSlot）】
  day8SlotGrantSizeForHandoff() スピン付与（今は3）
  → arrived → スピン実行 → 手番終了 → waitingSlot

【次の自分の手番】
  また都度付与（前手番の残りは持ち越さない）
```

- **早くゴール** → 残りラウンド分、自分手番が増える → 結果的にスロット多め
- **15T目（最終移動）でゴール** → 移動で手番消費、次手番なし → **スロットなし**
- **借金中もスピン可**
- **JP** → POTリセット、**同じ手番の残スピン内**で続行
- ~~`reservedSlotTurns`~~ **廃止**（2026-07）

実装: `beginDay8SlotSeatForPlayer`, `day8SlotGrantSizeForHandoff`, `isDay8FinalMoveGoal`

## 脱落・代理スロット（マルチ）

- 借金トラップ / 人助け即死で脱落
- 他プレイヤーが盤上（`moving`）にいる間、**代理スロット**で干渉可
- 標的の所持金30%までベット、500G以下は選べない
